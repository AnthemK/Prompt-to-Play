# 邮件交付

类型：**规则文件**。[每日流程](daily-brief.md) · [简报档案](../../editions/README.md)

1. 以已核验的一期简报为依据，写英文邮件正文：概述、各独立事件的摘要及原文链接，可适度精简；保留事实归属和重要不确定性。
2. 标题使用 `codeX整理的每日新闻简报｜YYYY-MM-DD`，重发修订版时明确标注。收件人按用户本次或适用的既有授权确定；历史收件地址不等于自动定时发送授权。
3. 独立附上完整版 Markdown 或 PDF；把输入快照、候选台账、必要复核说明与清单打成资料包。正文不能只写附件介绍或技术统计。
4. 在本期 `delivery/` 保存邮件正文与附件。资料包清单写清内容和限制，不包含缓存、重复文件或不必要中间数据。
5. 用户授权发送后通过 Gmail 接口发送；记录返回的邮件 ID、收件人、标题和发送状态。标记 `SENT` 证明已发送，不证明收件人已阅读。失败或状态不明时先查询，避免重复发送。
6. 检查附件完整性，清理 `tmp/`。保留已发送版本；更正需另存并明确说明。

2026-10-03 的更正版已在对话中得到 `SENT` 回执，但本地未保存完整邮件正文及发送回执文件。后续交付按上述规则留档；不以新写文件冒充当日原件。
