# 媒体视角与横向比较台账（初版，2026-09-30）

“立场”至少包含出资/所有权、编辑使命、目标读者、选题重心和某个事件中的具体框架。下表只写能从媒体自己公开资料确认的**背景或自述**；“应比较的视角”是溯闻的编辑检查项，不是对该媒体每篇报道的预设结论。新闻、社论、评论、分析须分开记录。每个背景来源和判断日期都要保留。

## 同一事件的比较格式

| 字段 | 记录内容 |
| --- | --- |
| 共同事实 | 各报道均支持的事实，每条附原文链接和发布时间 |
| 差异 | 标题用词、先后顺序、强调的受影响者、解释框架、遗漏的关键背景 |
| 争议断言 | 谁提出、哪家报道、是否有一手文件或独立证据支持；不把主张写成事实 |
| 来源谱系 | 原创采访/现场、通讯社转载、引述同一政府通报、独立文件；折算独立证据数 |
| 地区/利益视角 | 当事地媒体、周边国家、国际媒体及公共/商业/国家资助背景 |
| 仍待确认 | 数据冲突、报道更新、无法访问的正文、可能需要的下一手来源 |

每个事件优先找当事地原始报道、一家以上独立国际报道、相关一手文件。为了“覆盖立场”不能把证据不足的说法与经过核实的事实并列成各占一半。重大差异要引用文章中的具体段落或可核查摘要，并标明是溯闻的比较判断。

一手文件另设类别（例如政府公告、法院材料、企业披露、[WHO](https://www.who.int/news-room) 原始发布及 [OCHA ReliefWeb](https://apidoc.reliefweb.int/) 的原机构报告）。ReliefWeb 汇集伙伴内容，须回到原发布机构；其 API 还要求预批准的 appname。这些资料用来核实断言，不当作与媒体同类的“独立报道”。
