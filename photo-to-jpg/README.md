# 照片转 JPG

离线批量将照片转换并压缩成 JPG，不需要 AI 或上传照片。支持 JPG、JPEG、PNG、WebP、BMP、TIFF 和 GIF。

## 运行

需要 Python 3 和 Pillow；非 macOS 系统的图形界面还需要 Tkinter。在终端进入这个文件夹，首次运行时安装依赖：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

macOS 上会依次弹出系统对话框，选择照片文件夹、一个已有的输出文件夹，再输入质量并点击「开始转换」。转换期间终端会显示进度，完成后弹窗显示结果。默认质量为 55；质量越低文件通常越小，但画质也会下降。压缩后的文件不一定比原文件小。其他系统使用图形窗口。

使用 `-h` 或 `--help` 查看所有命令行参数：

```bash
.venv/bin/python app.py --help
```

运行自动测试：

```bash
.venv/bin/python -m unittest -v
```

也可通过命令行运行：

```bash
.venv/bin/python app.py /照片文件夹 /输出文件夹
```

指定输入和输出文件夹后，程序只会在终端询问质量，直接回车使用默认值 55。也可添加 `--quality 55` 跳过询问，方便脚本调用。

使用 `--delete` 可在转换和核对成功后清空输入文件夹（包括其子文件夹），保留输入文件夹本身：

```bash
.venv/bin/python app.py /照片文件夹 /输出文件夹 --delete
```

也可以单独运行 `.venv/bin/python app.py --delete`，通过对话框选择文件夹。删除无法撤销，请确认输入文件夹正确。

如果没有清空输入文件夹，可以只读检查两边文件数量和不支持的文件，不会再次转换或删除：

```bash
.venv/bin/python app.py /照片文件夹 /输出文件夹 --inspect
```

## 处理规则

- 递归处理子文件夹，输出中保留相对目录结构；未指定 `--delete` 时原文件不会被修改。
- 输出文件夹不能与输入文件夹相同，也不能互为上下级。已有文件和同名图片不会被覆盖，会自动添加数字后缀。
- 每张图片输出超过 1 MB（1,048,576 字节）时，质量降低 10 并重新压缩，最多重试三次（最多降低 30）；达到 1 MB 或以下或质量降至 1 时停止。重试后仍可能超过 1 MB。
- 透明区域填充白色；动画只转换第一帧。自动应用 EXIF 方向，其他元数据不会保留。
- 不支持的文件会跳过；损坏或无法读取的图片会在结果中显示失败，其他图片继续处理。
- 压缩过程在本机完成；安装依赖时需要网络。非 macOS 系统的部分 Python 安装可能需另外安装 Tkinter。

- 结束时递归统计输入和输出文件夹中的所有文件（包括不支持的文件和已有文件，但忽略 macOS 的 `.DS_Store`），并报告数量是否一致。
- 指定 `--delete` 时，仅在至少成功转换一张图片、所有输入文件均成功转换、数量一致、输入文件未变化且没有符号链接时清空输入文件夹；否则保留输入文件并报错。清空时也会删除输入目录中的 `.DS_Store`。建议使用空的输出文件夹。
