# 新增一个站点

1. 建立 `sites/<站点简称>/`，参考 SJMC 放入 `README.md` 和 `task.template.json`。模板不含账号、密码、Cookie 或访问令牌。
2. 为每个实际账号选择唯一的 account，例如 `another-forum-main`；为每项任务选全局唯一 id。不要复用 `sjmc`。
3. 确认入口、登录页、允许的 HTTPS origins，以及稳定的登录成功、任务完成和验证码选择器。登录标记应选主内容区，不依赖折叠侧栏。
4. 模板中 schedule.enabled 设为 false。在管理页新建任务并粘贴模板。
5. 用工具的独立窗口登录，保存登录态，再手动运行。验证成功状态，随后重复运行确认不会再次提交。
6. 最后启用每日/每周计划；记录首次跨日结果。模板保留暂停状态，避免他人导入即自动执行。

支持 goto、click、fill、wait、request 步骤；优先使用浏览器按钮操作以保留网站自己的 CSRF 与表单逻辑。验证码需人工处理。第三方登录所需来源必须逐个确认，不能为了方便无限放开。

若改任务账号：创建新的任务 ID 和 account 并重新登录，暂停旧任务；不要在文件系统直接重命名账号文件夹。当前界面没有任务删除功能。
