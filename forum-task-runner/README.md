# 本地论坛任务工具

已实现首版本地网页工具（2026-10-21）：Playwright 浏览器操作、共享 Cookie 的 HTTP 步骤、每日/每周调度、本地加密登录态、运行记录及重复执行防护。SJMC 已验证登录态复用与已签到识别；次日自动提交及 Windows 尚未实机验证。

## 在这台 Mac 体验

双击 `demo.command`，打开终端中显示的完整网址。依赖已放在项目目录，本机可使用已有 Edge；浏览器使用独立会话，不读取你的个人浏览器资料。

1. 在任务卡上点击登录，在弹出的演示论坛点击“模拟登录”。
2. 回到管理页，保存登录态，然后执行任务。
3. 查看成功记录；重复执行不会再次提交签到。
4. 演示任务默认暂停调度，点击启用才会自动执行。

演示完全使用本机假论坛，不需要注册。演示论坛重启会丢失模拟账号状态；任务历史仍保留，可新建不同 id 的演示任务再次体验。不要把模拟登录当成真实网站验证。

## 在其他机器安装

安装 Node.js 24 或更高版本，在本目录运行：

```sh
npm ci
npm run browser:install
npm run demo
```

正式使用运行 `npm start`，也可使用 Mac 的 `start.command` 或 Windows 的 `start.ps1`。浏览器安装到项目 `.browsers` 目录。首次下载依赖和浏览器需要联网。本机依赖通过 npm 官方归档下载并校验 SHA-512 后安装；其他机器的 `npm ci` 流程尚未实机验证。

## 接入网站

点击“新建任务”，编辑 JSON 配置；可参考演示任务或 `examples/task.json`。每个站点需要确认登录成功、任务完成、人机验证的页面标记，以及具体步骤，不能仅填网址就自动适配。

步骤支持 `goto`、`click`、`fill`、`wait`、`request`，可用 `skipIf` 跳过已完成步骤。HTTP 步骤共享当前浏览器 Cookie，支持 GET/POST，禁止自动跳转。相同账号的任务填写相同 `account`，且必须使用一致的允许来源列表。

注册、密码登录和验证码由你在独立浏览器中完成，随后保存登录态。不要把密码填进任务 JSON；自动填充会拒绝密码框。检测到配置中的验证码标记会停止；本版不自动破解验证码，也没有验证码云服务。执行中出现验证时需重新打开登录窗口处理，再根据运行记录决定是否重跑。

## 定时运行

服务运行时每 30 秒检查调度。同周期自动尝试一次；已完成不重复提交。提交后无法确认结果会标为“结果不确定”，必须检查站点状态后手动确认重试，避免重复操作。

Mac 可在关闭手动启动的服务后运行 `npm run autostart:mac`，设置登录系统后常驻；撤销用 `npm run autostart:remove`。本机已为 SJMC 安装自启动。 Windows 可用任务计划程序在登录时运行 `node src/server.js`，起始目录设为项目目录；尚未实机测试。

电脑关机或休眠时不能执行。每日任务按指定时区的当天运行窗口补跑，不跨午夜补昨天任务；周任务按星期和窗口判断。去重周期为当地自然日/周一开始的自然周，暂不支持凌晨 4 点等自定义重置时间。

## 数据与网络边界

- 管理页仅监听 `127.0.0.1`，启动链接含本次会话访问令牌，请勿分享。
- 不接入模型 API、遥测或第三方验证码服务。目标论坛本身仍需联网，登录密码通过 HTTPS 交给该论坛；无法做到“登录却完全不联网”。
- 配置、Cookie、Local Storage、IndexedDB 状态按账号用独立密钥加密，存入 `.data/accounts/<account>/` 的数据库；密钥也在该账号目录。它能降低单独数据库泄露的风险，不能防止已控制本机的程序读取密钥。Windows 文件 ACL 尚未加固。
- 浏览器请求按允许来源拦截，禁用 Service Worker 和 WebSocket，保持 TLS 证书校验；这不是操作系统级的网络隔离保证。允许来源内的站点脚本仍能操作该站点页面及表单。
- 默认无截图、录屏、trace 或请求正文日志；运行记录保留状态与步骤信息。不要上传 `.data`、`.browsers` 或个人配置。
- Session Storage、复杂跨站登录/弹窗、多因素认证及站点专属 CSRF 参数仍需逐站适配。登录态不能保证永久有效。
