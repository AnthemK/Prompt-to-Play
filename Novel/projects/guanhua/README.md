# 观化

《观化》是中文仙侠长篇，当前主宗门为太一门。创作性文档以中文为准；外部资料可保留原文与少量必要术语。

项目现阶段以基础设定收束为主，卷一正文暂停推进。各项判断以其所在目录的正式文件为准，本页只作入口。

## 项目入口

- [MEMORY.md](MEMORY.md)：当前状态与交接。
- [TODO.md](TODO.md)：待办与未决事项。
- [docs/README.md](docs/README.md)：协作规范与写作流程。
- [00-reference/README.md](00-reference/README.md)：外部参考与阅读研究。
- [01-立项/README.md](01-立项/README.md)：立项判断、题材承诺与主题。
- [02-设定/README.md](02-设定/README.md)：世界、修行及后续设定。
- [03-人物/README.md](03-人物/README.md)：人物档案与索引。
- [04-剧情/README.md](04-剧情/README.md)：大纲与剧情结构。
- [05-正文/README.md](05-正文/README.md)：正文草稿。
- [06-修订/README.md](06-修订/README.md)：修订记录。
- [07-发布/README.md](07-发布/README.md)：对外材料。
- [08-experimental-writing/README.md](08-experimental-writing/README.md)：实验性写作运行区。
- [09-cache/README.md](09-cache/README.md)：临时上下文缓存。

`08-experimental-writing/` 与 `09-cache/` 是运行层，不作为正式设定出处。

阅读时从本页进入下一层 README，再由该层索引到本层文件或下一层 README。具体设定只在对应的正式文件中维护。
