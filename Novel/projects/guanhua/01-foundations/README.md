# 01-foundations

这个目录处理《观化》的立项层。

这一层只放上位约束，不展开世界设定、人物正文或剧情细纲。

## 文件索引

- `project-brief.md`
  - 项目总说明，回答“这是什么书”
- `genre-promise.md`
  - 类型承诺，回答“向读者承诺什么体验”
- `thematic-core.md`
  - 主题核心，回答“这本书真正追问什么”
- `novel-style-principles.md`
  - 文风与思想原则，回答“这本书该怎么写”

## 建议阅读顺序

2. `genre-promise.md`
