# Long Arc Blueprint

## 用途

定义整本书的长线结构。

这份文档不只负责列长线节点，  
也负责立住整本书在剧情层必须长期遵守的推进原则。

## 一、建议填写

- 开局状态
- 主线冲突
- 中段升级
- 关键反转
- 后期逼近
- 终局方向

## 二、长线叙事约束

### 1. 故事必须真实

这里的“真实”，不是要求一切都灰暗或琐碎，  
而是要求人物的：

- 选择
- 代价
- 欲望
- 误判
- 关系变化

都要像这个世界里真的会发生的事。

如果一段剧情只完成了“信息推进”或“情节转场”，  
却没有带出真实的人物判断与后果，它就还不够成立。

### 2. 生存逻辑必须进入叙事

本书必须长期吸收这些硬逻辑：

- 稀缺
- 准备
- 代价
- 风险

但吸收它们的方式，不是把文本写成：

- 道具目录
- 资源表格
- 交易流水账

更合适的做法是：

- 用具体资源推动行动
- 用准备过程塑造人物
- 用代价与后果加重胜负
- 用风险判断显出角色层次

### 3. 设定必须反复承担剧情功能

任何重要设定都不应只负责“显得很厉害”或“显得世界很大”。

更合适的标准是：

- 它是否会在多个剧情节点中被实际调用
- 它是否会改变人物关系、资源分配或冲突结构
- 它是否会影响主角的判断、选择或代价

如果一项设定脱离剧情也能完整存在，那它大概率仍停留在材料层，而没有真正进入小说本体。

本书尤其要坚持这一点：

- 宗门制度要服务于人物处境
- 功法、法宝、峰脉要服务于冲突和命运
- 地理空间要服务于行动与记忆
- 关系与感情线相关设定要服务于人物判断、立场拉扯与命运变化

### 4. 真实不等于情感贫血

人物之间当然可以有交换、有算计、有留手。  
但本书不能因为强调秩序、资源与代价，就把情感写空。

仍要保留：

- 被改变的痕迹
- 被辜负的痛感
- 被理解或错失的情感重量

真正有分量的长线，不只是靠事件升级，  
也靠这些关系与心性的后果不断沉积。
