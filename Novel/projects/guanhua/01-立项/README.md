# 01-立项

这个目录保存《观化》的立项基础：作品定位、思想立场、读者承诺与表达原则。

这里规定作品必须坚持什么；世界、人物与剧情在各自目录继续展开。这里不定义具体世界机制，也不编排剧情细纲。

## 文件索引

- `项目简述.md`
  - 项目总说明，回答“这是什么书”
- `题材承诺.md`
  - 类型承诺，回答“向读者承诺什么体验”
- `主题内核.md`
  - 思想底色与主题核心，回答“这本书真正追问什么”
- `文风原则.md`
  - 表达与审美原则，回答“这本书该怎么写、如何使用思想资源”

## 建议阅读顺序

1. `项目简述.md`
2. `题材承诺.md`
3. `主题内核.md`
4. `文风原则.md`

上一级入口见 `../README.md`。
