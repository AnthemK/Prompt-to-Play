# 规则账本

## 用途

本文件是底层规则的追责索引，不重复定义规则。

- 规则正文统一见 `世界核心规则.md`。
- “主要展开”只记录最直接的下层正文；跨体系规则不强行指定单一文件。
- 新增或修改规则时，先改正文，再更新本表。
- 尚无合适正文的位置标为 `TODO`，不以 README 代替。
