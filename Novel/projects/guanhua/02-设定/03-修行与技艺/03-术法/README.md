# 03-术法

本目录处理术法、法门与秘术：修士在既有修行根基上，能够习得并施展哪些具体手段。

## 文件索引

- `术法总论.md`：术法体系总纲；定义术与功法、法宝、百艺的边界，以及术法的成立条件、用途与层级限制。
- `正统术法/README.md`：正统术法及具体条目的入口。
- `炼体术法/README.md`：炼体手段及具体条目的入口。
- `神道术法/README.md`：神道术法的入口，仍属 `TODO`。
- `炼神术法/README.md`：已废弃的炼神、炼魂术法旧笔记入口，仅供追溯。
- `旁门禁术/README.md`：旁门术法、禁术及具体条目的入口。

## 阅读顺序

1. `术法总论.md`
2. 各分类目录的 `README.md`
3. 需要时再读具体术法条目

## 边界

- 功法塑造长期修行结构，术法处理具体运用；二者不可互相代替。
- 本目录不重新定义修途、功法、百艺或宝物，也不编排具体人物的战斗过程。
- 具体术法只说明个案，不得反向改写术法总纲；神道术法须在功法与术法总纲校准后再展开。

上一级入口见 `../README.md`。
