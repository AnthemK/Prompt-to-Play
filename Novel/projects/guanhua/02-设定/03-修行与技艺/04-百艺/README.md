# 04-百艺

本目录处理百艺：通过长期准备、资源转化、造物、养护与环境经营来塑造修行条件的技艺。

## 文件索引

- `百艺总论.md`：百艺总纲；定义百艺与功法、术法、法宝的边界及五门分工。
- `阵法.md`：阵法；组织力量、借用地势并塑造环境。
- `炼器.md`：炼器；处理材料、器图、器纹与器物炼成过程。
- `炼丹.md`：炼丹；依丹方转化药材并制成丹药。
- `医养.md`：医养；诊、治、调、养活体状态。
- `灵兽技艺.md`：灵兽；处理灵兽的使用与协同，当前故意不展开完整驯养学。

## 阅读顺序

先读 `百艺总论.md`，再按需要进入各门文件。炼丹与医养、炼器与法宝容易混淆，阅读时应优先核对各自主文件中的边界说明。

## 边界

- 百艺重在长期塑造条件，不是功法、即时术法或成品宝物的别称。
- 本目录负责五门百艺的技艺规则，不编排具体人物选择、堂口经营、商路或剧情流程。
- 符纹是多门百艺共用的技术语言，当前不另立为第六门。
