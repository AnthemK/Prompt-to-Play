# 03-修行与技艺

本目录处理修行者如何修、如何运用力量、如何长期塑造条件，以及如何借宝物承载和放大道途。

## 目录索引

- `TMP.md`：从索引撤出的候选设定暂存，非正式设定出处。
- `01-修途与境界/README.md`：修途与境界，回答“修什么、如何分层”。
- `02-功法/README.md`：功法与传承，回答“怎么修、如何塑形”。
- `03-术法/README.md`：术法与法门，回答“如何具体施展”。
- `04-百艺/README.md`：百艺，回答“如何长期造物与塑造条件”。
- `05-宝物/README.md`：宝物，回答“哪些成物能够被持有、祭炼与传承”。

各目录的直接文件、状态与进一步入口，见各自 `README.md`。

## 阅读顺序

按目录编号阅读。先立修途与境界，再读功法、术法、百艺与宝物。

## 边界

- 天地、灵气、界域、因果、生死与天劫的底层机制不在本层定义。
- 宗门、势力、地域、历史、人物与剧情只引用本层规则，不在这里展开。
- 下层条目不得反向改写总纲；神道功法与术法的具体结构仍待其各自目录定稿。

上一级入口见 `../README.md`。
