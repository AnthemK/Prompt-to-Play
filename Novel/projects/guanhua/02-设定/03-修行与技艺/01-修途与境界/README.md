# 01-修途与境界

本目录定义修行的主干、公共境界尺度与主要修途，只回答“修什么、如何分层、为何受限”。功法、术法、百艺与宝物的具体实现不在此展开。

## 文件索引

- `修行总纲.md`：修行总纲；定义修行的性质、共同基础及三条主路。
- `六境通则.md`：六境的唯一公共定义；说明不同修途为何可以共用同一层级尺度。
- `修道.md`：正统修道；说明其主流地位、路线特征及六境中的具体表现。
- `炼体.md`：炼体一道；定义以肉身为主承载的修途。
- `神道.md`：神道主定义；说明神位、来源、传承、香火与飞升边界。
- `炼神旧稿-已废弃.md`：已废弃的炼神旧稿，仅供追溯。
- `炼魂旧稿-已废弃.md`：已废弃的炼魂旧稿，仅供追溯。
- `兼修与三修.md`：兼修与三修的成立条件、收益和风险。
- `破境与岔路.md`：破境、失败、失衡、走偏与岔路。
- `资粮与瓶颈.md`：资粮、瓶颈及修行所依赖的环境与组织条件。

## 阅读顺序

1. `修行总纲.md`
2. `六境通则.md`
3. 三条修途文件
4. `兼修与三修.md`
5. `破境与岔路.md`
6. `资粮与瓶颈.md`

## 边界

- 六境的公共含义只在 `六境通则.md` 定义；各修途文件只写本路线的具体表现。
- 本目录不展开功法结构、术法运用、百艺流程、宝物规则及具体宗门或人物个案。
- 神道功法与术法仍须由下层文件独立定稿；炼神、炼魂旧稿都不能作为现行规则。
