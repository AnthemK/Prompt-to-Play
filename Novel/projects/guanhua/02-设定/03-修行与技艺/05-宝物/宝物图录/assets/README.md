# 宝物图录配图

本目录只存放宝物条目的图像与辅助材料，不代替上一级条目正文。资产与正文冲突时，以正文为准；临时实验图不自动成为正式设定。

## 目录索引

- `中和道碑/README.md`：中和道碑配图。
- `筑基期法宝/README.md`：筑基阶段器型合集配图。
- `金丹期宝物/README.md`：金丹阶段宝物类型合集配图。

## 对应原则

独立条目的资产目录以宝物主名称命名；合集的资产目录以合集文件名命名，目录内再按各宝物名称区分文件。概念图、示意图、细节图及必要的简短说明可放在这里；宝物的核心设定仍写在条目正文。具体字段和条目组织方式以 `宝物图录/` 的 `条目模板.md` 为准。

同一素材有多个版本时，应在文件名中标明用途或版本，避免把临时图误作定稿。
