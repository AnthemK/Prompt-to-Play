# 宝物图录

本目录收录可直接用于创作的宝物条目；宝物系统的总纲、规则和分类由上层文件维护。

## 文件索引

- `条目模板.md`：条目写法、字段取舍及独立文件与合集的主规范。
- `中和道碑.md`：重要宝物独立条目。
- `筑基期法宝.md`：筑基阶段常见器型合集。
- `金丹期宝物.md`：金丹阶段宝物类型合集。
- `assets/README.md`：配套图像与辅助材料的目录入口。

## 阅读与维护

先看 `条目模板.md`，再按宝物名称进入条目；需要配图时，从 `assets/README.md` 继续查找。同一件宝物只保留一个主条目，正文优先于配图；新增条目的字段和资产对应方式以模板为准。
