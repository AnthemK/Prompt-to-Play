# 05-宝物

本目录以具体宝物为主体，处理可被持有、祭炼、封存、争夺或传承的成物，不讨论其炼制过程。

## 文件索引

- `宝物总论.md`：宝物体系唯一总纲；定义何谓宝物及其与百艺、术法、活物的边界。
- `品级与契合.md`：规则层；定义品级、品质、契合、认主、温养及宝物难以完全度量的原因。
- `器物型宝物.md`：已经成型的器物型宝物。
- `天然宝物与奇物.md`：天然宝物、奇物与异宝。
- `本命宝物.md`：与修士长期深度绑定的本命宝物。
- `战略重宝.md`：与宗门、王朝或其他势力绑定的战略重宝。
- `宝物图录/README.md`：具体宝物条目库；条目规范由其本层文件索引。

## 阅读顺序

先读 `宝物总论.md` 与 `品级与契合.md`，再进入分类文件和具体条目。

## 条目原则

- 剧情中重要、独特且会反复调用的宝物使用独立文件。
- 低阶、量产或阶段性常见宝物可以合集收录。
- 条目只写个案，不反向定义宝物通则。

## 边界

炼器回答“如何造”，宝物层回答“成物是什么、如何与人及势力发生关系”。具体人物持有什么宝物及其剧情用法，不在此决定。
