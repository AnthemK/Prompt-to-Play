# 02-功法

本目录处理修道、炼体的功法：功法为何产生、如何传承，以及一门功法怎样塑造修士。神道不修功法，其具体体系暂置于本目录，目录归属留待后续复核。

## 文件索引

- `功法总论.md`：功法体系总纲；定义功法的来源、社会地位、评级、流通、秘传、残卷与法脉维护。
- `功法结构.md`：功法结构总纲；定义单门功法的内部构成、适配、塑形、配套接口与同源演化。
- `正统功法/README.md`：正统功法及具体条目的入口。
- `炼体功法/README.md`：炼体功法的入口。
- `神道体系/README.md`：具体神道体系个案的暂置入口，不是功法分类。
- `炼神功法/README.md`：已废弃的炼神、炼魂功法旧稿入口，仅供追溯。
- `旁门禁法/README.md`：旁门功法与禁法的入口。

## 阅读顺序

修道、炼体先读 `功法总论.md` 与 `功法结构.md`，再进入对应子目录的 `README.md`。神道直接从 `神道体系/README.md` 查个案，不以功法总论为前提。

## 边界

- `功法总论.md` 负责功法在修仙世界中的位置与外部关系；`功法结构.md` 负责单门功法本身。
- 本目录不重新定义修途与境界，不展开术法、百艺或宝物体系，也不决定具体人物如何获得功法。
- 具体功法与神道体系只能表现个案，不得反向成为通用模板；《中和经》只代表其自身。
- `神道体系/` 暂置于此，记录神道修行所依托的具体体系，不充当单门功法。

上一级入口见 `../README.md`。
