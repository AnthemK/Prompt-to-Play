# 01-秩序总图

这个目录处理 `05-势力与政体/` 之下的**总图层**。

这里不写具体势力档案，而写它们背后的共性框架。  
它主要回答：

- 这个世界里有哪些主要秩序类型
- 不同类型的势力通常如何成立、维持与扩张
- 它们通常能管什么、依赖什么、如何互动、为何被承认

换句话说：

- 这里写“共性”
- 不写“个案”

## 本目录负责什么

本目录主要用于：

- 为各类具体势力提供统一分类框架
- 说明势力之间常见的权力边界、资源关系与互动方式
- 说明地位、名分与承认如何在本世界中成立

如果要新建一个势力档案，通常应先阅读本目录。

## 本目录不负责什么

具体势力档案，以及世界底层规则、天地法理、修行技艺与历史格局，都不在这里定义。需要时先返回上一级 README，再逐层进入对应目录。

## 文件索引

- `秩序类型.md`
  - 说明本世界主要秩序载体的类型划分

- `权柄与辖域.md`
  - 说明不同类型势力通常能管什么、管到哪

- `依附与资源关系.md`
  - 说明不同类型势力通常依赖什么资源与关系网络

- `冲突结盟与干预.md`
  - 说明不同类型势力通常如何冲突、结盟与彼此介入

- `地位合法性与承认.md`
  - 说明不同类型势力为何被承认、视为正统、附庸或僭越

## 建议阅读顺序

首次进入本目录，建议按以下顺序阅读：

1. 本 README
2. `秩序类型.md`
3. 其余四个文件按任务需要阅读
4. 再进入对应类型的具体势力目录

## 最后说明

这一层的作用，是为后续所有具体势力档案提供一个统一前提：

- 先理解框架
- 再建立个案

具体势力的辖地、结构、人物、资源与剧情功能，不在这里展开。

上一级入口见 `../README.md`。
