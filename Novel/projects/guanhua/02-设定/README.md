# 02-设定

这个目录处理《观化》的正式设定层。

这一层回答“世界如何运转”，不负责人物正文与剧情细纲。

## 目录索引

- `IDEA.md`
  - 尚未归档的设定候选，非正式设定出处
- `01-世界宪则/README.md`
  - 宪法层，处理世界底层公理与统一约束
- `02-天地法理/README.md`
  - 宇宙本体层，处理天地、灵机、界域、因果、生死、飞升等根本问题
- `03-修行与技艺/README.md`
  - 修行技术层，处理修途、功法、术法、百艺与宝物
- `04-天下格局与历史/README.md`
  - 世界格局与历史层，处理时代、时间线与世界展开骨架
- `05-势力与政体/README.md`
  - 势力与政体层，处理宗门之外的现实秩序载体
- `太一门/README.md`
  - 太一门专章，处理卷一最常用的宗门近景设定
- `06-设定索引/README.md`
  - 设定参考层，处理术语表、命名样本与设定辅助索引
- `assets/README.md`
  - 共用图像与示意资源规则

## 建议阅读顺序

1. 先读本目录 README
2. `01-世界宪则/README.md`
3. `02-天地法理/README.md`
4. 按任务进入 `03-修行与技艺/`、`04-天下格局与历史/`、`05-势力与政体/` 或 `太一门/`

上一级入口见 `../README.md`。
