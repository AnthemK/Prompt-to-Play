# 02-天地法理

这个目录处理《观化》的宇宙本体与根本法则，说明底层公理如何展开为天地、灵气、界域、因果、生死与飞升等超凡现象。

这里不定义具体境界、功法、术法、势力、人物或剧情。

## 文件索引

- `天地与道.md`
  - 本层总纲。定义天、地、道的关系，以及修士认识和改造世界的边界。
- `灵气与流转.md`
  - 定义灵气的性质、流动、转化、载体与失衡。
- `界域与边界.md`
  - 定义主世界、洞天、秘境、小世界、异质界域及其边界。
- `气运因果与天机.md`
  - 定义气运、因果、命数、征兆、天机与卜算。
- `生死神魂与肉身.md`
  - 定义肉身、神魂、生死、轮回，以及魂体独存、附体与夺舍。
- `飞升与天劫.md`
  - 定义天劫、越界、飞升接口与高阶存在面对的秩序压力。

## 建议阅读顺序

1. `天地与道.md`
2. `灵气与流转.md`
3. `界域与边界.md`
4. `气运因果与天机.md`
5. `生死神魂与肉身.md`
6. `飞升与天劫.md`

## 边界

- 本层只定义宇宙机制；底层公理、修行方式与社会秩序各有上层目录所示的独立出处。
- 若新设定改变了宇宙规则或引入高阶例外，应先回到本层校准，不在下层临时补写。
