# 01-人物索引

这个目录放角色系统的总索引与总账。

## 文件索引

- `人物总索引.md`：人物总表与阅读入口。
- `人物关系图.md`：人物之间的关系线。
- `主要人物弧光索引.md`：主要人物的阶段性变化索引。

## 这个目录解决什么问题

它主要回答：

- 角色系统整体怎么读
- 先看谁、后看谁
- 角色之间的关系和弧光如何挂接

适合放：

- 角色总表
- 关系图
- 弧光总索引

这里不放单个主要角色的正式人物档。

这里也不负责机械定位问题。

如果你只是想快速确认“某个角色的正式 Markdown 在哪里”，请先回到上一级 `../README.md`，再进入结构化导航目录。

## 给协作者的建议

如果你刚进入角色层，建议先读这个目录，再决定要不要继续深入主角档、主要角色档或群像文档。

上一级入口见 `../README.md`。
