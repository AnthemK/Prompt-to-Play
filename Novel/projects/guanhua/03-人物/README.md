# 03-人物

本目录处理人物的叙事功能、基础设定、关系与弧光，不写剧情细纲。人物发生稳定变化时，回填其唯一主档。

## 子目录索引

- `01-人物索引/README.md`：人工阅读的人物总表、关系与弧光索引。
- `02-主角/README.md`：陆守一的正式档案与近景环境。
- `03-主要人物/README.md`：单独立传的主线级人物。
- `04-群像/README.md`：卷级配角组与群像。
- `结构化索引/README.md`：角色档案的机器可读导航。

主要人物单独立传，次要角色可按功能合并；升格后应拆档。阅读具体内容，请逐层进入对应目录的 README。

上一级入口见 `../README.md`。
