# 03-主要人物

这个目录放需要单独立传的主要角色。

## 文件索引

- `关键师长.md`：周既白当前人物档案，姓名仍按正文标为暂定。
- `关键师长原型.md`：关键师长的早期构思，用于追溯，不替代现行档案。
- `重要女角色一.md`：顾清栩当前人物档案，姓名仍按正文标为暂定。

## 这个目录解决什么问题

它主要回答：

- 哪些角色已经升格为主线级人物
- 这些人物的基础设定和卷一位移是什么

当前标准：

- 对主线有长期结构性影响
- 不是一组群像里的一个点，而是能单独承担人物弧光

这类角色必须单独开文件。

## 给协作者的建议

如果任务涉及周既白、顾清栩等主线级人物，不要只看群像文档，先来这里读正式人物档。

上一级入口见 `../README.md`。
