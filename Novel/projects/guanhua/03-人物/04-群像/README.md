# 04-群像

这个目录放角色组与群像文档。

## 文件索引

- `第一卷配角群像.md`：第一卷关键配角及合并人物档案。

## 这个目录解决什么问题

它主要回答：

- 配角群像怎么分层
- 卷一关键配角由哪些人构成
- 哪些角色还未升格为单独立传

适合放：

- 卷级关键角色组
- 某一阶段的同辈组、外门组、地方组

原则：

- 次要角色同类型可合并到组文档
- 但一旦角色升格为主要角色，应拆出去单独立传

如果你只是想快速确认某个配角目前落在哪个合并文件、哪一节，请先回到上一级 `../README.md`，再进入结构化导航目录。

## 给协作者的建议

如果你在做群像、同辈气氛、配角口风或开篇人物分布实验，这里比主要角色档更重要。

上一级入口见 `../README.md`。
