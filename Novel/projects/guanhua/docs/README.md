# 项目规范

本目录维护《观化》的协作、文档与写作规则，不承担小说的正式设定、人物或剧情内容。需要查找规范时，先在这里确定职责，再进入本层文件。

## 文件索引

- `DOC_GOVERNANCE.md`：文档层级、唯一出处与 README 导航规则。
- `NAMING_RULES.md`：目录、文件、章节及过渡期命名规则。
- `WORKFLOW.md`：从参考、立项到发布的工作流程。
- `WRITING_EXECUTION_RULES.md`：写作执行约束。
- `QUALITY_BARS.md`：各阶段的质量门槛。
- `TERM_GLOSSARY_RULES.md`：术语表的维护规则。
- `CACHE_POLICY.md`：临时上下文缓存的使用边界。
- `CACHE_TEMPLATE.md`：缓存条目的模板。

上一级入口见 `../README.md`。
