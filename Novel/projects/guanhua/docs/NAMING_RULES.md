# 命名规范

## 用途

本文件规定《观化》项目的路径命名。目标是让目录可判读、可检索、排序稳定，并使索引与引用易于维护；命名不能代替文件边界。

## 一、中文为主，编号保序

- 新建的创作性目录与文件，原则上使用简洁、准确的中文名称，例如 `01-立项/项目简述.md`、`02-设定/02-天地法理/生死神魂与肉身.md`。
- 有顺序的阶段、层级和章节保留阿拉伯数字及前导零，例如 `03-修行与技艺/`、`第001章.md`。名称不随临时理解频繁更改。
- 文件名应说明职责或对象，优先使用项目已定术语；不为追求古意而使用难懂、易混或过宽的词。
- 不使用空格、问号、斜杠等不利于路径引用的字符；扩展名保持 `.md`、`.json`、`.png` 等原有格式。

## 二、保留稳定入口

- 各级目录入口仍称 `README.md`，项目状态和任务仍称 `MEMORY.md`、`TODO.md`。这些是协作约定，不视为创作性命名例外。
- 已有的 `00-reference/` 来源入口、`docs/` 规范文件、`assets/` 资产入口及 `08-experimental-writing/`、`09-cache/` 运行目录保留技术性标识；它们不构成创作性文件改回英文的先例。
- 结构化索引、外部导入原件和来源文件不因中文化而自动改名；确需改动时，应连同使用方、来源记录及路径引用一起核验。
- 废弃稿用 `-已废弃` 明示状态，并在正文开头说明现行主出处；临时稿应说明归宿，不靠 `TMP`、`final` 等含混名称长期留存。

## 三、人物、卷章与资产

- 独立人物档案使用正式姓名；姓名未定时，先使用清楚的角色职责名，不以猜测的汉字替换英文转写。
- 卷与章使用稳定序号，例如 `第一卷/`、`第001章.md`、`第001至010章细纲.md`。卷号、章号与文件内容须相符。
- 图像名称可采用中文对象名及用途，例如 `中和道碑/主概念图.png`；移动图像时同步核对正文中的相对图片链接。

## 四、路径与迁移

- README 只索引本层直接文件与下一层目录；跨层阅读经各级 `README.md` 逐层展开。具体规则见 `DOC_GOVERNANCE.md`。
- 正文文件尽量独立，必要引用优先留在同目录。跨目录主出处追踪仅在确有维护价值时使用，不因改名增加新的交叉依赖。
- 改名须同时更新 Markdown、JSON、资产链接和规范中的路径，检查是否存在重名与旧路径残留，并验证目标真实存在。
- 项目正分轮次迁移。尚未迁移的旧英文目录暂可沿用，但新文件不得以此为由恢复“全英文优先”的旧规则。
