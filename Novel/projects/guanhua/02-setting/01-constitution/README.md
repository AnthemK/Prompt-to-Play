# 01-constitution

这个目录处理《观化》世界最底层、最稳定的结构约束。

这里不展开具体修炼路线、势力档案、地理格局或剧情个案，只负责回答：

- 这个世界为何能长期运转
- 超凡力量改写了哪些基本规则
- 后续设定必须共同服从哪些底层准则

## 文件索引

- `world-core.md`
  - 本层主文件。集中定义世界核心准则，以及后续设定进入正式层前必须回答的通用问题。
- `rule-ledger.md`
  - 本层规则追责索引。用于登记已经稳定进入底层的规则，并记录其主定义位置与后续回填状态。

## 建议阅读顺序

1. `world-core.md`
2. `rule-ledger.md`

## 使用原则

- 先在 `world-core.md` 中确认规则本体
- 再在 `rule-ledger.md` 中确认该规则是否已经被正式登记
- 若新增或改写底层规则，应先修改正文，再回填账本

## 边界

- 这里是索引与底层约束入口，不代替具体设定正文
- 若问题已经进入修炼体系、组织结构、历史演变或卷内使用层，应去对应下层目录继续展开
