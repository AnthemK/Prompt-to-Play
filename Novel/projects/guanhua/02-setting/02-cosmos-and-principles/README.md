# 02-cosmos-and-principles

这个目录处理《观化》的宇宙本体与根本法则。

这一层不写具体境界流程，不写具体功法条目，也不写宗门、人物和剧情个案。  
它只解释本世界的宇宙层、界域层与超凡现象层如何成立，并为后续修炼体系、术法体系、组织秩序与历史演变提供共同前提。

## 这个目录解决什么问题

这一层主要回答：

- 天、地、道在本世界中分别意味着什么
- 灵气为何存在，以及它如何流动、聚散、转化、存储与失衡
- 主世界、洞天、秘境、小世界与界域边界如何成立
- 气运、因果、征兆、天机与卜算为何能够成立
- 肉身、神魂、生死边界为何可以被修行触及
- 天劫、越界与飞升接口在本世界中意味着什么

## 与上下层的边界

这一层负责：

- 宇宙本体
- 天地法则
- 灵气结构
- 界域结构
- 因果与气运
- 魂身关系
- 天劫与越界

这一层不负责：

- 具体境界设计与修炼流程
- 具体功法、术法、法宝、丹药、符箓、阵法条目
- 宗门、世家、王朝、种族、地域等具体社会结构
- 历史事件、人物经历与正文桥段
- 正邪判断、组织合法性、社会规范与治理逻辑的具体展开

更准确地说：

- 如果问题是“这个世界为什么能这样运转”，先看 `../01-constitution/`
- 如果问题是“这些底层规则在宇宙与超凡现象层面怎样展开”，看本目录
- 如果问题是“修士具体怎么修、术法技术怎样落地”，去 `../03-cultivation-and-arts/`
- 如果问题是“世界地理、历史、势力与治理如何运转”，去 `../04-world-layout-and-history/` 与 `../05-factions-and-polities/`

## 核心判断主出处

README 只做索引，不重写各文件的正式判断。  
如果你要找本层最常用的判断，主出处如下：

- 天行有常、天地不仁；道无偏私，但会回应扰动；认识世界是改造世界的前提：见 `heaven-earth-and-dao.md`
- 灵气依附条件而存在，完整条件稀缺；同一法则在不同层次修士眼中会呈现不同复杂度：见 `spiritual-energy-and-flows.md`
- 主世界是当前唯一默认的完整秩序主体；边界是秩序差异形成的过渡层；当前阶段不实设完整上界，只保留向外接口：见 `realms-worlds-and-boundaries.md`
- 气运主要作用于宏观层面；因果首先是结构绑定；卜算可窥而不可尽知：见 `fate-karma-and-omens.md`
- 肉身与神魂存在分层；生死边界可被撬动，但不能被轻飘飘抹除：见 `life-death-soul-and-body.md`
- 天劫兼具自然性与秩序性；飞升首先是越界问题，而不是奖励问题：见 `ascension-and-heavenly-tribulation.md`
- 一切力量都对应成本、超凡现象必须能回到统一世界论基础等更高阶约束：见 `../01-constitution/world-core.md`

## 文件索引

本目录遵循唯一定义原则：核心概念以各自主定义文件为准，其他文件只可引用或补充，不应随意重定义。

- `heaven-earth-and-dao.md`
  - 本层总纲。定义天、地、道的关系，以及修士为什么只能在理解规律之后借势、转移、重组或局部改写世界。
- `spiritual-energy-and-flows.md`
  - 定义灵气的性质、来源、流动、聚散、转化、存储与失衡规则，并说明阴阳五行如何作为主流描述框架进入修行世界。
- `realms-worlds-and-boundaries.md`
  - 定义主世界、洞天、秘境、小世界与界域边界的差别，以及不同界域为何会形成不同的承载、压制、筛选与向外接口。
- `fate-karma-and-omens.md`
  - 定义气运、因果、征兆、天机与卜算的作用边界，说明它们如何影响势力、法统、血脉与时代变化。
- `life-death-soul-and-body.md`
  - 定义肉身、神魂、生死边界、魂体独存、附体与夺舍的基本关系，为后续灵魂相关设定提供底层约束。
- `ascension-and-heavenly-tribulation.md`
  - 定义天劫、越界、飞升接口与高阶存在所面对的秩序压力，说明本界为何会对高层次存在作出回应。

## 给协作者的建议

如果你正在做修炼体系：

- 先确认 `../01-constitution/world-core.md`
- 再确认 `heaven-earth-and-dao.md` 与 `spiritual-energy-and-flows.md`
- 最后进入 `../03-cultivation-and-arts/`

如果你正在做术法、法宝、丹符阵器：

- 先确认 `spiritual-energy-and-flows.md`
- 再确认 `life-death-soul-and-body.md` 与 `fate-karma-and-omens.md` 中与你的方向有关的边界
- 最后进入 `../03-cultivation-and-arts/`

如果你正在做秘境、洞天、地图与遗迹：

- 先确认 `realms-worlds-and-boundaries.md`
- 再用 `spiritual-energy-and-flows.md` 与 `ascension-and-heavenly-tribulation.md` 校准资源与危险层级
- 需要落地到区域与历史时，转去 `../04-world-layout-and-history/`

如果你正在做高阶人物、顶层博弈与大事件：

- 先确认 `fate-karma-and-omens.md`
- 再确认 `life-death-soul-and-body.md` 与 `ascension-and-heavenly-tribulation.md`
- 涉及组织与治理后果时，再转去 `../05-factions-and-polities/`

## 使用原则

这一层只提供宇宙本体与超凡现象层的正式定义，不代替下层正文。

后续若出现以下情况，应优先回到 `../01-constitution/` 或本目录修正，而不是在下层文件中临时补丁：

- 某种超凡现象改变了世界的基本运行逻辑
- 某类高阶手段绕开了既有代价结构
- 某种界域、因果、生死或天劫设定与既有文件冲突
- 某项技术或剧情需要引入新的宇宙层级规则

如果你只需要快速确认“这个设定能不能成立”，先读本目录 README，再去对应正文文件查正式定义。
