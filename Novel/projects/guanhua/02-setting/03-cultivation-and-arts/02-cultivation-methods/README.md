# 02-cultivation-methods

这个目录处理本项目中的功法层。

它主要回答两类问题：

- 功法为何会在修仙世界中产生，并成为宗门、世家与法统体系里的核心资产
- 一门功法本身如何成立、如何塑造修士、如何沿同源主干发生结构演化

## 这个目录解决什么问题

这一层主要处理以下内容：

- 功法在修行体系中的地位是什么
- 功法为何不是附属技巧，而是修行路径的中轴层
- 一门功法通常由哪些结构部分组成
- 功法会把修士塑造成什么样的人
- 功法如何与资源、法宝、传承和法统发生关系
- 不同修途会形成怎样的典型功法形态

## 边界

本目录负责：

- 功法的总体地位、分类、评级与社会作用
- 功法本身的内部结构、适配性与结构演化
- 正统、炼体、炼魂、旁门与禁法等不同功法大类的典型画像
- 功法与传承、秘传、残卷、法脉维护、断代失传之间的关系

本目录不负责：

- 修途与境界的基础定义
- 斗法风格、战斗流程与术法分类
- 丹、符、阵、器、医护、御兽等百艺细节
- 法宝体系本身的完整分层与条目库
- 具体人物最终学了哪门功法、如何在剧情中得到该功法

换言之，本目录定义“功法是什么、如何成立、如何传承、如何分化”，  
不直接展开“怎么打”“器物怎么做”“谁已经学会了哪一门法”。

## 分层与索引

### `method-system.md`
**功法体系**

这是本目录关于“功法为何产生、在世界中如何运转”的主定义文件。  
它负责：

- 功法的来源、修订与创法
- 功法在修行世界中的总体地位
- 功法的社会流通、占有、评级与稀缺性
- 残卷、秘传、选择性授受、法脉维护与断代问题
- 功法与资源、法宝、法统等其他层的总体互动

### `method-structure.md`
**功法结构**

这是本目录关于“功法本身怎样组成、怎样改变修士”的主定义文件。  
它负责：

- 一门完整功法通常有哪些结构部分
- 适配性为何首先是结构问题
- 完整法与残缺法在结构上差在哪里
- 同源功法如何在保持主干可追溯的前提下发生分支与演化
- 功法如何预设修士对器物与配套体系的结构接口

## 建议阅读顺序

建议按以下顺序阅读：

1. `method-system.md`
2. `method-structure.md`
3. `orthodox-methods/README.md`
4. `body-methods/README.md`
5. `soul-methods/README.md`
6. `heterodox-and-forbidden-methods/README.md`

这个顺序的目的，是先明确功法在世界中的位置，再明确功法本身的结构；  
在此之后，再分别进入不同功法大类的子目录继续下钻。

## 使用原则

本目录先立功法层的骨架，不追求一次性写尽所有具体功法。  
当前阶段的目标是：

- 先明确功法的总体地位与内部结构
- 先确定各大类功法的上位边界
- 先为第一卷必然会用到的关键功法保留稳定落点

因此，本目录允许保留以下接口：

- 具体根本法、辅法与专门法的后续增补
- 某些宗门独门功法与断代功法的后续补充
- 炼魂功法体系正式收束后的补档
- 与特殊资源、特殊器物、特殊环境深度咬合的具体功法条目

但所有后续补充，都应服从本目录已经确定的主出处与边界，  
不应在下层文本中反向改写本层结构。
