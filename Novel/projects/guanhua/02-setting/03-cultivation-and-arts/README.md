# 03-cultivation-and-arts

这个目录处理本项目中的修炼体系、功法体系、术法体系、百艺体系与宝物体系。

它主要回答的是：在既定天地法则下，修行者如何修、如何承载、如何出手、如何长期塑造条件，以及如何借助宝物放大自身道路。

## 这个目录解决什么问题

这一层主要处理以下内容：

- 修仙六境为何能成为天下通用的层级尺度
- 正统修仙、炼体、炼魂等主要修途如何成立
- 功法为何是修士根基，以及功法如何塑造道路差异
- 术法、法门与具体手段如何在功法基础上展开
- 阵、器、丹、医养、灵兽等百艺如何嵌入修行世界
- 宝物、本命宝物与战略重宝为何会成为力量与法统的载体

## 边界

本目录负责：

- 修途与境界
- 功法与传承
- 术法与法门
- 百艺与长期技术体系
- 宝物与重器

本目录不负责那些看起来很像修炼内容、但实际上属于更上层世界论的部分，例如：

- 天地本体、道的性质、灵气与界域的根本法则
- 气运、因果、天机、生死边界与天劫的底层机制

本目录也不负责那些会使用修炼体系、但实际上属于更下层世界展开的部分，例如：

- 宗门、世家、王朝、种族、地域等具体组织结构
- 历史事件、人物经历与正文桥段

## 建议阅读顺序

建议按以下顺序阅读：

1. `01-paths-and-realms/`
2. `02-cultivation-methods/`
3. `03-mystic-arts/`
4. `04-esoteric-crafts/`
5. `05-treasures-and-artifacts/`

这个顺序的目的，是先立修行主干，再立功法根基；在此之后，术法、百艺与宝物才能不彼此混淆。

## 使用原则

本目录只抓主干，不求一次写尽。

当前阶段的目标是先建立清楚、简练、可扩展的骨架，而不是把所有细节一次性定死。  
因此，本目录允许在下一级目录中保留适度接口，用于后续补充具体修途差异、功法演化、偏门百艺、特殊术法与宝物条目。

但所有后续补充，都应服从本目录已经确定的分层与边界，不应在下层目录中反向改写本层结构。
