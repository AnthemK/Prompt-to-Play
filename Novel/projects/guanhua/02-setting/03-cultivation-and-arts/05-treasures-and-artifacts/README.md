# 05-treasures-and-artifacts

这个目录处理本项目中修仙世界里的**宝物体系**。

这里讨论的不只是法宝，  
也包括那些本身就足以被争夺、封存、传承、炼化或作为组织底蕴的珍稀宝物。

## 这个目录讲什么

这一层主要处理：

- 宝物本身是什么
- 宝物大致可以如何分类
- 宝物的品级、品质、契合、认主与温养应如何理解
- 不同类型宝物在个人与组织层面分别有什么意义

## 这个目录不讲什么

这一层不处理：

- 宝物如何被炼制出来的具体流程
- 炼器、炼丹、阵法等百艺本身的技术体系
- 具体术法如何借助宝物施展
- 修士的修途、境界与功法体系
- 具体人物持有哪件宝物的剧情安排

换言之，本目录讨论的是：

> **宝物本身是什么。**

而不是：

> **它是如何被造出来的，或修士拿着它具体怎么施术。**

## 文件索引

### `treasure-system.md`
**宝物系统唯一总纲**

适合先读。  
用于把握这一层的总体边界，并理解：

- 什么才算宝物
- 宝物为何首先是“物”
- 为什么这一层讨论的是宝物对象，而不只是法宝功能
- 05 与百艺、术法、活物之间的总体边界是什么
- 宝物为何会因个人、体系、组织与时机不同而改变意义

这是本目录的唯一主定义文件。  
关于“宝物总论”“什么才算宝物”“为什么进入 05”“05 与其他体系怎么分”等判断，  
均应以 `treasure-system.md` 为主；  
其余文件只负责规则层、分类层与条目层，不反向重写总纲。

### `grades-and-compatibility.md`
**宝物规则层**

处理宝物的基础规则，重点包括：

- 品级
- 品质
- 契合
- 认主
- 温养
- 宝物为何有价值基准，却难以完全统一度量

它不再承担 05 的总纲定义，  
而是在 `treasure-system.md` 已经立住总边界之后，负责规则层。

### `artifact-treasures.md`
**器物型宝物**

处理已经成型、可被持有、祭炼、认主和传承的器物类宝物。

### `natural-treasures-and-oddities.md`
**天然宝物与异宝**

处理那些并非人为炼成、却本身就具有独立价值的天然宝物、奇物与异宝。

### `natal-treasures.md`
**本命宝物**

处理与修士个体深度绑定、可长期温养并与道路相关联的本命宝物。

### `strategic-treasures.md`
**战略重宝**

处理与组织、宗门、王朝或一方势力绑定的重宝与底蕴之物。

### `treasure-codex/`
**宝物条目库**

用于后续收录具体宝物条目。  
当前阶段主要保留：

- 条目库入口规则
- 条目规范主文件
- 条目资产组织方式

这里有三条内部入口：

- `treasure-codex/README.md`：条目库入口与收录原则
- `treasure-codex/entry-template.md`：条目规范主文件
- `treasure-codex/assets/README.md`：条目资产目录规则

此外，剧情中重要、独特、会持续反复调用的宝物，应尽量使用**独立文件**；  
低阶、量产型、阶段性常见宝物，则允许使用**合集文件**集中收录。

## 建议阅读顺序

建议按以下顺序阅读：

1. `treasure-system.md`
2. `grades-and-compatibility.md`
3. `artifact-treasures.md`
4. `natural-treasures-and-oddities.md`
5. `natal-treasures.md`
6. `strategic-treasures.md`
7. `treasure-codex/README.md`

先看 `treasure-system.md`，再看 `grades-and-compatibility.md`，再进入分类层与条目库。  
这样可以先立住“宝物系统是什么”，再进入“规则层怎么运作”。

## 使用方式

阅读本目录时，建议先分清：

1. 宝物体系与百艺体系的边界  
2. 不同类型宝物各自处理什么  
3. 哪些内容应进入具体宝物条目，而不是继续停留在总纲层

如果某件东西主要在回答“怎么造 / 怎么炼 / 怎么布 / 怎么养成条件”，应先回到 04；  
如果它主要在回答“这件物本身是什么、为何值得持有、争夺、封存或传承”，再进入 05。
