# 第一卷

这个目录专门放第一卷的大纲材料。

## 这个目录解决什么问题

它主要回答：

- 第一卷为什么这样排
- 五阶段怎么咬合
- 每一章在结构上承担什么功能
- 当前卷一已经细到什么程度

## 放什么

- 第一卷卷纲
- 第一卷阶段事件链
- 第一卷角色推进拆分
- 第一卷章纲

## 不放什么

- 世界设定正文
- 宗门制度设定
- 正文草稿

补充：下山任务的通用模型归设定层；主角第一次下山的具体事件链归本目录。

## 给协作者的阅读建议

如果你只做卷一实验，建议顺序是：

1. 先读本目录 README
2. 再读 `第一卷卷纲.md`
3. 再读 `第一卷骨架复核.md`
4. 任务偏结构时看 `章纲.md`
5. 任务偏开篇落文时看：
   - `第001至010章细纲.md`
   - `第011至020章细纲.md`
   - `第021至028章细纲.md`

上一级入口见 `../README.md`。
